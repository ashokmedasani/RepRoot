# .gitignore

## What this file does

Excludes generated dependencies, Angular build output, Angular cache files, local dev-server logs, and package manager debug logs from version control.

## Why this file exists

The repository should track source code and documentation while keeping generated local artifacts out of Git.

## Page or module

Project-level development configuration.

## Important entries

- `node_modules/`: installed npm dependencies.
- `dist/`: Angular production build output.
- `.angular/`: Angular local cache.
- `.dev-server/`: local logs from the helper server script.
- `.venv/`: local Python virtual environment.
- `__pycache__/`: Python bytecode cache folders.
- `.env`: local environment variables and secrets.
- `db.sqlite3`: accidental local SQLite database files.
- `postgres_data/`: accidental local PostgreSQL volume folder if bind-mounted later.

## Data flow

No product data flows through this file.

## Connected files

- `frontend/package.json`
- `scripts/start-dev-server.ps1`
- Angular build tooling
- Django local development tooling
- Docker Compose local database tooling

## Business logic

None.

## Assumptions

Generated output should be reproducible from source files and should not be committed.

## Future improvements

Add deployment-specific ignored files when deployment tooling is approved.
