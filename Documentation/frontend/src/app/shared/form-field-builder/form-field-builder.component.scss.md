# frontend/src/app/shared/form-field-builder/form-field-builder.component.scss

## What this file does

Styles the reusable dynamic field builder.

## Why this file exists

The field builder needs a clear editor/preview layout that works across lead form and client form setup pages.

## Important styling

- Two-column field editor and live preview layout.
- Compact choice and compound input previews.
- Responsive single-column layout on smaller screens.
