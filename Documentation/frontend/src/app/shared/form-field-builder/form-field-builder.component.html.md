# frontend/src/app/shared/form-field-builder/form-field-builder.component.html

## What this file does

Renders the reusable dynamic field editor and preview UI.

## Why this file exists

The guided setup pages need custom field controls that preview each field type as the applicant or trainer will see it.

## Important sections

- Field label, type, required/optional, placeholder, help text, and options controls.
- Live preview for phone, date, location, address, dropdown, checkbox, radio, and text fields.
- Empty custom-field state.
