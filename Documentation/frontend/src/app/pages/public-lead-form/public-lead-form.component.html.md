# frontend/src/app/pages/public-lead-form/public-lead-form.component.html

## What this file does

Renders the public trainer lead form and success screen.

## Why this file exists

Applicants need a simple public page that displays all configured Form 1 fields and confirms their generated reference ID after submission.

## Page or module

Public lead form page.

## Important sections

- Public form header with trainer name and form title.
- Dynamic field rendering for all form fields.
- Real controls for phone, choice, date, location, and address fields.
- Submit button.
- Success screen with reference ID and email confirmation message.
