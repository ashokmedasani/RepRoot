# frontend/src/app/pages/trainer-account-settings/trainer-account-settings.component.html

## What this file does

Provides the HTML template for trainer account settings.

## Why this file exists

Trainers need account settings for password changes and account deletion, with shared trainer navigation across implemented sections.

## Page or module

Trainer Settings page.

## Important sections

- Top trainer navigation with Profile, Forms & Groups, and Settings links.
- Change Password form.
- Delete Account action.

## Business logic

The Forms & Groups navigation item links to the implemented `/trainer/forms-groups` page.
