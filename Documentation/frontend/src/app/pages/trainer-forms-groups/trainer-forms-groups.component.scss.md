# frontend/src/app/pages/trainer-forms-groups/trainer-forms-groups.component.scss

## What this file does

Styles the trainer Forms & Groups dashboard page.

## Why this file exists

The Forms & Groups dashboard needs visually separate sections for form status, submissions, and groups.

## Page or module

Trainer Forms & Groups page.

## Important styling

- Empty-state screen.
- Screenshot-style Public Lead Form card with stats and field summary.
- Form Requests table with status tabs.
- Green-tinted group rows with View users and edit form actions.
- Detail and client access panels.
- Mobile fallbacks for grids and action rows.
