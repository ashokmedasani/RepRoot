# backend/.env.example

## What this file does

Shows the environment variables used by the Django backend for local development.

## Why this file exists

Developers need a safe template for configuring Django and PostgreSQL without committing real secrets.

## Page or module

Backend project setup.

## Important functions/classes/components

None.

## Data flow

Environment values flow into `backend/config/settings.py`.

## Connected files

- `backend/config/settings.py`

## Business logic

None.

## Assumptions made

Local PostgreSQL defaults use database `trainer_platform`, user `postgres`, password `postgres`, host `localhost`, and port `5432`.

## Future improvement notes

Add separate deployment environment examples when hosting is selected.

## 2026-07-13 production audit

The example now lists database URL, browser origins, Redis, S3-compatible storage, request-throttle rates, and configurable Version 1 plan limits. Empty cloud values preserve local development behavior.
