# Documentation

This folder mirrors the project codebase for technical documentation.

For every code file created or modified, create or update a matching Markdown file in this folder using the same path structure.

Example:

- Code file: `frontend/src/app/pages/landing/landing.component.ts`
- Documentation file: `Documentation/frontend/src/app/pages/landing/landing.component.md`

Each documentation file must describe:

- What the code file does.
- Why the file exists.
- What page or module it belongs to.
- Important functions, classes, or components.
- How data flows in the file.
- Which other files it connects to.
- Any business logic inside it.
- Any assumptions made.
- Future improvement notes.

`PRODUCT_RULES.md` remains the product source of truth. This folder documents implementation files as they are added.
